# PlaySync: listen together, in sync

## Overview

PlaySync lets people start a room, share a code and press play. Pause, skip and seek stay in step for everyone in the room, with chat running alongside. It serves **1,000+ registered users**.

## Architecture

- **Monorepo:** Turborepo with a Next.js web app and a Node.js real-time server, all in TypeScript.
- **Real-time layer:** Socket.io with **Redis pub/sub**, so room events fan out across server instances.
- **Data:** a normalized PostgreSQL schema through Prisma, with NextAuth for sign-in.
- **Delivery:** Dockerized services with a GitHub Actions pipeline and Jest unit tests.

## Results

- Sync drift cut from **120ms to 10ms (91% lower)** at **5K+ messages/sec**.
- Release time cut from **30 minutes to under 5 minutes** with automated CI/CD.
