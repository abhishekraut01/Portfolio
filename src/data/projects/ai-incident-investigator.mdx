# AI Incident Investigator

## Overview

When an application throws an error, engineers lose time on triage. This agent reads the error, gathers context, reasons through likely causes and proposes a code-level fix, so engineers start from a diagnosis instead of a stack trace.

## How it works

1. A **webhook** receives the production error and triggers the agent.
2. A **LangGraph agent** works through 4 tools:
   - **Semantic search** over a ChromaDB store of past incidents
   - **Code reading** of the files in the stack trace
   - **Log analysis** around the failure
   - **Patch generation** for the proposed fix
3. A **Next.js dashboard** shows the agent's reasoning step by step.

## Results

- **80% root-cause accuracy** on a seeded production bug benchmark.
